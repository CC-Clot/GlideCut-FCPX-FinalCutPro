### 关键技术问题与解决（重要）
**SwiftUI 的 `MenuBarExtra` 在本机 macOS 27.2 上无法渲染状态项图标** —— 实测：
- 系统日志显示场景已创建（`NSStatusItemSceneHostSettings`）
- 但 `CGWindowList` 查不到任何窗口，像素差分也确认无图标
- 即使最简实现（仅 SF Symbol + 无 Settings 场景）仍然不显示

**解决方案：改用 AppKit 的 `NSStatusItem` + `NSMenu`**，实测成功：
```
日志: 菜单栏图标已创建（NSStatusItem）
AX:   ✅ 图标数量 1, pos=(1767,3) size=(24x24)
像素: x=3543..3574 宽32px（启动时新增）
```

## 三、Option 平移：客观技术受限

### 尝试过并全部失败的方案
| 方案 | 结果 |
|---|---|
| 合成水平滚轮事件 | FCP 忽略（0.002% 变化） |
| 合成触控板式事件（带 scrollPhase） | 无稳定效果 |
| 带 momentumPhase 的惯性滚动 | 无效果 |
| AX 设置时间线滚动条值 | 滚动条 `AXHidden=1`、无 action，设值不生效 |
| 查 FCP 菜单中的平移命令 | 「时间线滚动」是勾选项，无平移命令 |
| FCP AppleScript 字典 | 仅暴露 frontmost 等，无时间线命令 |
| FCP 时间线 AX 元素探测 | 时间线区域 0 个可操作元素 |

### 根本原因
**FCP 完全忽略 CGEvent 合成的滚动/键盘事件**（实测 `Command+=` 也是 0.00% 无变化），
且时间线在 AX 层不暴露可操作控件。缩放能成是因为 FCP 有菜单命令可调，
而水平平移没有任何菜单或 AX 接口。

### 建议（需你决策）
1. 改用键盘快捷键触发平移（需修改产品定义）
2. 放弃平移，V1.0 只做缩放（核心价值仍在）
3. 接受此限制，在文档中标注
