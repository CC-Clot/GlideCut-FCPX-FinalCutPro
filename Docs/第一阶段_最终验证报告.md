## 一、核心结论

**Command + 滚轮 → FCP 时间线缩放：已真机验证成功。**
```
[转换] 滚轮向上·垂直 修饰键=Command
       前台应用 = Final Cut Pro <com.apple.FinalCutApp>
       ▶ FCP 缩放（向上）→ 已点击菜单「放大」

```

## 二、两大致命技术发现（决定了架构）

### 1. FCP 完全忽略 CGEvent 合成事件
| 测试 | 结果 |
|---|---|
| 合成 `Command + =`（FCP 官方放大快捷键） | **0.00% 变化，完全无效** |
| 合成普通滚轮事件 | **0.002% 变化，无效** |
| 合成水平滚轮事件（Option 平移） | **0.002% 变化，无效** |

**结论：不能靠事件注入控制 FCP，必须走 AX（辅助功能）菜单路径。**

### 2. 可行的唯一路径：AX 菜单驱动
- `显示 > 放大 / 缩小`：实测单次点击时间线变化 **47.6%** ✅
- `显示 > 缩放至窗口大小`：可用于重置

## 六、未解决问题

1. **Option+滚轮水平平移未实现**：FCP 忽略合成滚轮，AX 滚动条设值不触发重绘。
   待探索：时间线 `scrollToVisible` / AXAction / 或模拟触控板事件。
2. **TCC 授权与构建路径绑定**：adhoc 签名下每次 Debug 构建路径变化会导致授权失效。
   对策：固定从 `/Applications/GlideCut.app` 运行并授权一次。
3. **菜单驱动有 ~20ms 延迟**：高频滚动时缩放不如原生顺滑，需优化节流。
4. **修饰键自定义未实现**：设置界面只有开关与权限，尚无快捷键自定义。
5. **开机启动未实现**：`SMAppService`（macOS 13+）方案已确认可行。
