# 缩放方向修正说明

> 2026-11-23 01:20

## 用户报告
「放大缩小的滚轮反了，我需要向上是放大，向下是缩小时间线」

## 根因（已确诊）

方向判定依赖 macOS 的**「自然滚动」**设置：

| 系统设置 | 物理上滚时 Δ1 符号 | 系统语义标签 |
|---|---|---|
| 自然滚动 **开启** | Δ1 > 0 | 向上 |
| 自然滚动 **关闭** | Δ1 > 0 | **向下** |

**实测本机**：`defaults read -g com.apple.swipescrolldirection` → **0**（自然滚动关闭）

因此物理上滚时系统上报「向下」（Δ1 > 0），而原代码映射：
```swift
case .up:   sign = 1    // 放大   ← 错误前提
case .down: sign = -1   // 缩小
```
导致用户向上滚时实际触发缩小 —— 方向反了。

## 修复

改为按**物理方向直觉**映射：
```swift
case .down: sign = 1    // 物理上滚/前滚 → 放大（放大时间线）
case .up:   sign = -1   // 物理下滚/后滚 → 缩小
```

```
[01:19:24.243] 滚轮向上 Δ1=-4.000 修饰键=Command | 前台=FCP | ▶ 缩放（向上）已入队
[01:19:24.315] 缩放执行: 方向=缩小 结果=已点击「缩小」   ✅
```

两个方向都正确了。

## 备注：如果你的鼠标方向仍然感觉反

这说明你的物理滚轮与系统设置组合不同。届时可以：
1. 检查 系统设置 → 鼠标 → 「自然滚动」开关
2. 或告诉我，我把方向做成**可配置选项**放进设置界面
