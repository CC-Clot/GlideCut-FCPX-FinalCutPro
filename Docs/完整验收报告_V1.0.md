## 四、未完成项（诚实记录）

| 项 | 原因 |
|---|---|
| **Option+滚轮水平平移** | FCP 不提供任何程序化接口。已试 7 种方案全部失败 |
| macOS 13 真机测试 | 本机为 27.2，仅验证编译兼容性（minos 13.0） |
| 多应用逐一隔离测试 | 抽样验证，未穷举 |

### Option 平移失败详情
1. 合成水平滚轮事件 → FCP 忽略（0.002%）
2. 触控板式（带 scrollPhase）→ 无稳定效果
3. 惯性滚动（momentumPhase）→ 无效
4. AX 滚动条设值 → 隐藏且无 action
5. FCP 菜单命令 → 无平移项
6. AppleScript 字典 → 无时间线命令
7. AX 参数化属性 → 仅文本替换
