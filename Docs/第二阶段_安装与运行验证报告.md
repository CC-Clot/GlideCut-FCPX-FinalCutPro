## 四、关键技术发现（首次实测得出的重要事实）

运行 `GlideCutWheelProbe`（探针）**6 秒**，期间用合成器注入 5 组滚动事件（普通 / Command / Option / Control / Shift）：

```
[验证] CGEvent.tapCreate 成功，事件循环已启动
[23:05:12.293] 后台事件循环已就绪，开始监听滚轮事件
（注入 5 组事件：无任何一条被回调收到）
[23:05:18.296] 后台事件循环已退出...
```

**结论：在未授权输入监控时，`CGEvent.tapCreate` 能成功创建、RunLoop 也能跑，但回调根本收不到任何滚轮事件（合成事件也不进回调，注入的 5 组全部丢失）。**

这是 macOS TCC 的既定行为：**tapCreate 成功 ≠ 有权收事件**。单纯监听（listen-only）时，权限不足表现为"静默收不到事件"而非创建失败——绝不能把「tapCreate 成功」误判为「监听可用」。此点已写入技能库。
